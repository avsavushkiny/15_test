Объяснение кода
Это пример многопоточности в C++ с использованием спин-блокировки (spinlock)
для синхронизации доступа к общей переменной.

Пошагово:
1. Глобальная переменная и спин-блокировка (строки 7, 9-25)

int c = 0 — глобальная счётчик, к которому обращаются несколько потоков.
SpinLock — простая реализация спин-лока на базе atomic_flag:
lock() — бесконечно крутится в цикле (test_and_set), пока не захватит блокировку.
unlock() — освобождает блокировку (clear).

2. Функция работы с ресурсом (строки 27-35)
workOnResurse() — инкрементирует c 1 000 000 раз, каждый раз захватывая спин-лок.
Блокировка гарантирует, что инкремент c++ будет атомарным — два потока не смогут одновременно прочитать и изменить c.

3. Main (строки 37-48)
Создаются два потока (t1 и t2), оба вызывают workOnResurse().
join() — основной поток ждёт завершения обоих.

Выводит значение c.

Что на выходе?
Ожидаемый результат: 2000000 (2 × 1 000 000).

Без спин-лока результат был бы недетерминированным из-за race condition — инкремент c++ 
не атомарен по своей природе (read-modify-write).

Краткая схема работы:
Поток 1: [lock] c++ [unlock]  →  параллельно с
Поток 2: [lock] c++ [unlock]

Спин-лок обеспечивает взаимное исключение, но «занимает» процессор в цикле ожидания — 
отсюда название spin (крутится). Для длительных критических секций это неэффективно, 
но для коротких операций (как c++) — приемлемо.
